# LuatOS 设备支持计划 [已通过USB实现]

## Goal
添加 LuatOS 设备数据采集支持，实现 GPIB / LuatOS 双模式切换。

## 实现方式
最终以 **USB (libusb + pyusb)** 方式连接 IotPower-cc 设备，而非计划中所述的串口 (pyserial)。USB 实现覆盖了全部功能需求。

## Phase 4: Script Tab — Real Lua Execution Environment

### 4a. Add `lupa` dependency
- `requirements.txt`: add `lupa>=2.2`
- `pg-power.spec`: add `'lupa'` to hiddenimports
- lupa provides LuaJIT runtime accessible from Python

### 4b. Replace `_run()` exec with Lua runtime
```python
import lupa
from lupa import LuaRuntime

lua = LuaRuntime(unpack_returned_tuples=True)

# Expose serial/GPIB functions to Lua
lua.globals().g_send = g_send
lua.globals().g_qry = g_qry
lua.globals().s_send = s_send  
lua.globals().s_qry = s_qry
lua.globals().s_scan = s_scan
lua.globals().s_open = s_open
lua.globals().s_close = s_close

lua.execute(c)  # execute Lua script directly
```
