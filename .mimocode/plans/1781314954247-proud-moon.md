# LuatOS Serial Device Support Plan

## Goal
Add serial port support for LuatOS device data collection to PG-Power, with mode switching between GPIB and LuatOS.

## Phase 1: Library & Serial Functions

### 1a. Add dependency
- `requirements.txt`: add `pyserial>=3.5`
- `pg-power.spec`: add `'pyserial', 'serial.tools.list_ports'` to hiddenimports

### 1b. Add module-level serial functions
Insert after GPIB section (~line 88), mirroring the existing GPIB pattern:

```
# ===== LuatOS Serial =====
SERIAL_OK = False
serial_port = None
serial_lock = threading.Lock()
```
Functions:
| Function | Purpose |
|---|---|
| `s_scan()` | `serial.tools.list_ports.comports()` → list of device strings |
| `s_open(port, baud)` | Open `serial.Serial(port, baud, timeout=1)` |
| `s_close()` | Close & cleanup |
| `s_send(c)` | Write `c + \r\n` |
| `s_qry(c)` | Send + readline response |
| `s_readline()` | Non-query readline for continuous acquisition |

## Phase 4: Script Tab — Real Lua Execution Environment

### 4a. Add `lupa` dependency
- `requirements.txt`: add `lupa>=2.2`
- `pg-power.spec`: add `'lupa'` to hiddenimports
- lupa provides LuaJIT runtime accessible from Python

### 4b. Replace `_run()` exec with Lua runtime
```python
import lupa
from lupa import LuaRuntime

lua = LuaRuntime(unpack_returned_tuples=True)

# Expose serial/GPIB functions to Lua
lua.globals().g_send = g_send
lua.globals().g_qry = g_qry
lua.globals().s_send = s_send  
lua.globals().s_qry = s_qry
lua.globals().s_scan = s_scan
lua.globals().s_open = s_open
lua.globals().s_close = s_close

lua.execute(c)  # execute Lua script directly
```

### 4c. Script tab UI — add "发送到设备" button
- New button `btn_send` ("发送到设备") that sends script content to LuatOS device via serial
- For sending: `s_send(c)` to transmit script to device's Lua interpreter
- Keep placeholder text showing Lua syntax examples

### 4d. Lua examples in placeholder
