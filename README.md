# PG-Power

GPIB 电源实时采集与 IotPower-cc USB 功耗测试工具

基于 Python + PyQt5 + PyQtGraph 构建，支持 GPIB 电源控制和 IotPower-cc USB 功耗采集仪的实时数据采集、波形显示、数据分析与报告生成。

## 功能特性

### 设备支持
- **GPIB 电源**：通过 NI-488.2 驱动控制 GPIB 接口电源（如 Keysight 663XX 系列），支持 SCPI 命令
- **IotPower-cc USB 功耗仪**：上海合宙通信出品的 USB 功耗采集设备，支持微安级电流测量

### 核心功能
- **实时波形**：电压、电流、功率三条曲线实时绘制，支持双波形/合并模式切换
- **数据采集**：可配置采样率（50ms~200ms），自动保存 CSV
- **选区分析**：拖选时间区域，自动计算均值、最大值、最小值和电量
- **测试报告**：一键生成产品功耗测试报告（含波形截图、统计汇总）
- **脚本控制**：内置 Lua 脚本引擎，支持自动化测试序列
- **三步校准向导**：电压零位 → 电流零位 → 电压系数，引导式操作

### 显示特性
- 深色/浅色主题切换
- 自适应/固定/对数坐标模式
- 跟踪线、数据标签
- 截图保存

## 快速开始

### 环境要求
- Python 3.8+
- NI-488.2 驱动（仅 GPIB 模式需要，USB 模式不需要）
- Windows 10/11

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

或双击 `run.bat` / `run.ps1`。

## 使用说明

### USB 模式（IotPower-cc）

1. 切换到「设备与设置」标签 → 选择「LuatOS串口」模式
2. 点击「扫描设备」→ 在列表中选择 IotPower-cc → 点击「连接设备」
3. 按【三步校准向导】顺序依次完成校准：
   - **① 电压零位**：关闭电源输出(0V)后点击
   - **② 电流零位**：开启电源输出(>0V)，断开负载后点击
   - **③ 电压系数**：接入已知电压（如万用表实测值）后点击
4. 切换到「数据与波形」标签 → 点击「开始采集」

### GPIB 模式

1. 切换到「设备与设置」标签 → 选择「GPIB」模式
2. 设置电源型号、GPIB 板卡号和设备地址
3. 点击「连接设备」
4. 进行电流零位校准（断开负载后点击）
5. 点击「开始采集」

### 快速连接（工具栏）

使用下拉框选择设备类型（GPIB/USB），点击「连接」一键连接已识别的设备。

## 校准说明

正确的三步校准顺序：

| 步骤 | 操作 | 电源状态 | 负载状态 |
|------|------|---------|---------|
| ① 电压零位 | 点击测量 | **关闭 (0V)** | 无要求 |
| ② 电流零位 | 点击测量 | **开启 (>0V)** | **断开** |
| ③ 电压系数 | 输入已知电压后校准 | **开启** | 接好 |

校准结果保存在 QSettings 中，重启后自动恢复。

> **注意**：电压零位校准必须在电源关闭(0V)时进行，否则会导致电压读数异常。程序已内置合法性检查（`v_off > 500` 自动拦截）。

## 常见问题

**Q: 空载电流不归零？**  
A: 请执行「电流零位校准」—— IotPower 自身有 ~69µA 的空载功耗，校准后自动扣除。

**Q: 负载后电流不变化？**  
A: 检查 `s_readline()` 中的电流限幅器逻辑是否在负载切换检测之前运行。新版本已修复此问题。

**Q: GPIB 连接失败？**  
A: 确认已安装 NI-488.2 驱动，且 Python 位数与 DLL 位数一致（均为 64 位）。

**Q: 打包后的 EXE 缺少 Qt 平台插件？**  
A: 使用项目自带的 `pg-power.spec` 和 `pyi_hooks/` 打包，或直接使用 `打包PG-Power.bat`。
